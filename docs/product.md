# পণ্যের পরিধি

শিখক শিক্ষার্থী, শিক্ষক, অভিভাবক ও অ্যাডমিনের জন্য বাংলা-প্রথম EdTech marketplace। মূল প্রবাহ: শিক্ষক খোঁজা → প্রোফাইল/ডেমো → প্যাকেজ → স্লট → ডেমো পেমেন্ট → বুকিং → লোকাল ক্লাসরুম → নোট/পরীক্ষা → অগ্রগতি/রিভিউ।

লোকাল MVP-তে সক্রিয়: নিবন্ধন, RBAC, শিক্ষক প্রোফাইল ও গিগ, নিয়মভিত্তিক ম্যাচিং, তুলনা, প্রিয় তালিকা, বুকিং, লেজার, বার্তা, নোটিফিকেশন, MCQ, ক্লাসরুম, হোয়াইটবোর্ড, MediaRecorder, সমস্যা পোস্ট/অফার এবং অ্যাডমিন যাচাই। Recorded course-এর Prisma architecture প্রস্তুত; UI expansion-এর জন্য রাখা হয়েছে।
