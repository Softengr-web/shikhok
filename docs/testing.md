# পরীক্ষা

`npm.cmd run test` login hash validation, RBAC gate, registration, double-booking prevention, payment/ledger, server-side grading এবং duplicate review rule পরীক্ষা করে।

ম্যানুয়াল end-to-end পরীক্ষা: শিক্ষার্থী লগইন → শিক্ষক খোঁজা → গিগ → বুকিং → ডেমো পেমেন্ট → ক্লাসরুম → পরীক্ষা → রিভিউ। পরে শিক্ষক, অভিভাবক ও অ্যাডমিন ডেমো অ্যাকাউন্ট দিয়ে সংশ্লিষ্ট dashboard পরীক্ষা করুন।
